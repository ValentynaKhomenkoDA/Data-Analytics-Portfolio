## 🛠️ Skills & Technical Features Demonstrated
* **Calculated Fields & LODs:** Built custom logic, calculated average order value (AOV), and calculated percentage changes over time.
* **Interactive Filtering:** Implemented global, cascading filters and cross-dashboard actions for multi-dimensional filtering (by country, OS, browser, and traffic source).
* **Advanced Visualizations:** Designed dynamic trend lines, geographical maps, and cross-tab performance matrices for cross-market comparisons.
